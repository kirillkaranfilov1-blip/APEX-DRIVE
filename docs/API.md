# Локальный REST API

Все ответы — JSON. Локальная версия использует один профиль `local-player`, без регистрации. Клиент не передаёт цену автомобиля.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | Проверка доступности API. |
| GET | `/api/profile` | Создать при первом запросе и вернуть профиль игрока. |
| GET | `/api/catalog/vehicles` | Вернуть общий реестр машин. |
| GET | `/api/catalog/tracks` | Вернуть общий реестр трасс. |
| POST | `/api/vehicles/{vehicle_id}/purchase` | Проверить доступ, цену и баланс; выполнить атомарную покупку. |
| PUT | `/api/profile/selected-vehicle` | Выбрать только принадлежащую игроку машину. Тело: `{"vehicleId":"..."}`. |

Ошибка имеет форму `{"error":{"code":"...","message":"..."}}`. HTTP 409 используется для недостатка кредитов и повторной покупки, 403 — для закрытой машины или отсутствия владения.

Таблицы базы включают профиль, владение машинами, улучшения, карьерное состояние, результаты гонок и настройки. Пока нет обработчика завершения гонки и распределения наград: принимать награду от браузера небезопасно.
