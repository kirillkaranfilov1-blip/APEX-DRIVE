# Игровой UI/UX

- Навигация строится вокруг игрового действия: гонка, гараж, события; меню не должно выглядеть как админ-панель.
- Состояние интерфейса следует за состоянием игры и не меняет его незаметно.
- HUD читается периферийным зрением: цифры скорости/круга крупные, вторичные данные компактные, контраст устойчив.
- Кнопки имеют фокус клавиатуры, понятные подписи и визуальную обратную связь; горячие клавиши объяснены.
- Ограничивай анимации короткими переходами; учитывай `prefers-reduced-motion`.
- Проверяй ширину 320 px, большой текст, отсутствие WebGL и закрытие/возврат из паузы.
