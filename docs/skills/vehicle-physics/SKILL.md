# Физика машины

- Держи баланс в конфигурации конкретной машины: масса, двигатель, тормоз, сцепление, подвеска, радиус колеса и лимит скорости.
- Разделяй логику управления, физический корпус и визуальные детали. Колёса в raycast-модели — визуальные объекты, а не четыре независимых динамических тела.
- Ограничивай скорость руления с учётом скорости и сглаживай изменение угла; торможение и задний ход не должны включаться одновременно.
- Настраивай ручник как отдельное поведение задней оси; не делай его скрытым ускорителем поворота.
- Проверяй сцепление, остановку, реверс, отпускание газа, столкновение и сброс на фиксированном сценарии.
- Для визуальных колёс читай rotation/suspension из API контроллера Rapier, а не дублируй расчёт.
