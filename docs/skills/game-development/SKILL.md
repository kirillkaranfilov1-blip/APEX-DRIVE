# Разработка игры

1. До изменения найди владельца системы и прочитай `AGENTS.md`, архитектуру и план фаз.
2. Опиши границу задачи: ввод → игровое правило → отображение; сохраняй физику, рендер и UI отдельными слоями.
3. Новую механику сначала вырази тестируемыми правилами и состояниями, затем подключай к `Game`.
4. У каждого состояния определи старт, допустимые переходы, отмену и очистку ресурсов.
5. Проверяй `npm test`, `pytest` по затронутой области и production build.
6. Отчитайся о проверенном, незавершённом и следующем этапе отдельно.
