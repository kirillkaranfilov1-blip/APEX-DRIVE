# Игровой звук

- Начинай Web Audio после явного пользовательского жеста, повторно используй один `AudioContext`.
- Для двигателя разделяй слои по RPM/нагрузке и сглаживай частоту, чтобы избежать скачков.
- Микшируй engine, tires, effects, music и UI на отдельных узлах с сохранёнными настройками громкости.
- Ограничивай однотипные короткие события, освобождай узлы и декодированные буферы при выгрузке.
- Используй собственные или лицензированные записи; лицензии звуков и музыки документируй.
- Проверяй отключение звука, блокировку автозапуска браузером и несколько одновременных событий.
