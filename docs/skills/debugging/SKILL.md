# Отладка

1. Воспроизведи проблему на чистом запуске и запиши конкретные шаги и ожидаемое поведение.
2. Найди слой первого неверного состояния: ввод, физика, правило гонки, рендер, API или сохранение.
3. Сравни фактические величины с единицами, временным шагом, осями и порядком обновления.
4. Сократи сцену до минимального воспроизводимого случая; инструментируй временный вывод без шумного постоянного логирования.
5. Исправление закрепи тестом, который падает на исходной ошибке.
6. Повтори исходный сценарий, смежные регрессии и сборку; в отчёте укажи наблюдения.
