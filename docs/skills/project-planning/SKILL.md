# Планирование проекта

1. Сначала прочитай текущее состояние и существующий план фаз; не переносить будущую функцию в «готово» из-за пустой папки.
2. Разбей работу на независимые этапы с проверяемым результатом и понятными владельцами файлов.
3. Зафиксируй интерфейсы между физикой, сценой, UI, карьерой и API перед параллельной реализацией.
4. Старайся закончить один вертикальный пользовательский путь до добавления следующей ширины функций.
5. Рискованные библиотеки и внешние активы проверяй до кодирования; документируй ограничения.
6. Каждый отчёт содержит сделанное, затронутые файлы, команды проверки, ограничения и следующий этап.
