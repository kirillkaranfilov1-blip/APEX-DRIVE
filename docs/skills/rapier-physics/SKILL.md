# Rapier 3D

1. Сверь точную версию пакета и JS API по официальной документации Rapier.
2. Используй один мир на сцену и постоянный `dt`; накапливай время кадров и ограничивай число догоняющих шагов.
3. Сначала создай тело, затем коллайдеры и контроллеры. Исключай динамическое шасси из raycast колёс.
4. Обновляй контроллер машины до `world.step()`, применяй силы к телам через публичный API Rapier.
5. Фиксированные/динамические коллайдеры, массу, трение и масштаб указывай явно и в согласованных единицах.
6. Проверяй падение, туннелирование, контакт, возврат и освобождение `World`; не основывай тест на нестабильном визуальном результате.
