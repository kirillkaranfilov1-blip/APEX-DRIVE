# Производительность

1. Замерь FPS, длительность CPU-кадра, число draw calls, число треугольников и время физики на фиксированной сцене.
2. Определи целевое оборудование и профиль качества до изменения визуального бюджета.
3. Сначала оптимизируй горячие участки: повторная геометрия, дорогие тени, лишние объекты, физические запросы.
4. Инстансируй повторяемые модели, ограничивай разрешение текстур и избегай создания объектов каждый кадр.
5. Сохраняй неизменной измерительную сцену и сравнивай результаты до/после.
6. Не удаляй читаемость трассы или полезную физику ради красивого счётчика FPS.
