# Тестирование

- Тестируй чистую математику, переходы состояния, правила владения, покупок и API без WebGL.
- У каждого правила должен быть нормальный случай, граница и отказной случай.
- Тест состояния чекпоинтов подтверждает, что поздние ворота не принимаются до ранних.
- Backend использует временную базу; не обращается к профилю пользователя или общей базе.
- Перед выводом результата запускай полный тестовый набор для изменённого модуля и release-сборку.
- Отдельно описывай браузерные проверки, потому что unit-тест не подтверждает ощущения от управления.
