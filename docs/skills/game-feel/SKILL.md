# Игровой отклик

1. Определи, что игрок должен почувствовать и по какому сигналу он поймёт действие.
2. Свяжи скорость с расстоянием камеры, FOV, звуком и обратной связью шины малыми плавными изменениями.
3. Не добавляй постоянное дрожание камеры; сильный эффект применяй только к ясному событию и затухай быстро.
4. Дрифт должен быть виден и слышен, но не скрывать траекторию и контрольные ворота.
5. Сделай настройки интенсивности для движения камеры, визуальных эффектов и аудио.
6. Проверяй обратную связь на трогании, резком торможении, заносе и столкновении.
