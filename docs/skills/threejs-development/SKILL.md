# Three.js

- Проверяй установленную версию и актуальные типы Three.js перед использованием недавно добавленных API.
- Сцена содержит только представление. Динамическая геометрия должна синхронизироваться с состоянием физики, а не заменять его.
- Объединяй повторяющиеся объекты в `InstancedMesh`; ограничивай размер теневой карты и число динамических источников света.
- Для текстур задавай цветовое пространство и фильтрацию намеренно; учитывай бюджет памяти и draw calls.
- При выгрузке освобождай GPU-ресурсы, созданные модулем; не освобождай общий ресурс, которым владеет другой модуль.
- Проверяй изменение размеров окна, потерю WebGL-контекста, адаптивное разрешение и производство-сборку.
