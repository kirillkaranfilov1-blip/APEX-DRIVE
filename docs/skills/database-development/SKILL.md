# База данных

- Сохраняй только долгоживущие данные; временную симуляцию гонки не записывай в SQLite каждый кадр.
- Включай foreign keys, `CHECK` для границ и уникальные ключи для владения/улучшений.
- Покупка выполняется в одной транзакции с проверкой баланса, владения, разблокировки и списанием.
- Схемные изменения оформляй пронумерованными миграциями, когда появится первая существующая база у игроков.
- Проверяй повторный запрос, нехватку средств и целостность после ошибки транзакции.
- Настрой резервное копирование и безопасное восстановление до выпуска сохранений.
