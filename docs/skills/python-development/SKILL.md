# Python API

- Размещай создание приложения и зависимости в `create_app`, чтобы тесты использовали временную SQLite.
- Маршруты валидируют вход, сервисы реализуют правила, слой данных отвечает за транзакции.
- Возвращай стабильный код ошибки и корректный HTTP статус; не отправляй traceback клиенту.
- Не считай любые поля клиента авторитетными для денег, победы, цены или прогресса.
- Используй контекстное закрытие соединений и параметризованный SQL.
- Проверяй успешные ответы, неверные тела, отсутствие владения, границы значений и rollback.
