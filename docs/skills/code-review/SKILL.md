# Проверка кода

- Сверь изменение с требованием и архитектурным владельцем; проверь, что в diff нет посторонних файлов.
- Проверь источники данных и границы доверия: клиент не назначает цену, награду или владение.
- Проверь API библиотек по установленным версиям, корректность единиц и порядок обновления физики.
- Ищи утечки слушателей, объектов Three.js, соединений SQLite и таймеров.
- Запусти затронутые тесты и production build; комментарии ревью должны указывать конкретный риск и сценарий.
- Не называй проверенным поведение, которое не запускалось.
